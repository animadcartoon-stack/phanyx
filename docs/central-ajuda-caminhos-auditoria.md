# Auditoria dos caminhos da Central de Ajuda

209 artigos revisados em cinco idiomas (1045 versões).

A verificação confere o catálogo, os controles de origem e a renderização. Não comprova autenticação, permissões ou funcionamento completo das telas protegidas.

Os mapas visuais são representações dos itens de navegação; não são prints de uma sessão de usuário. Os prints existentes do conteúdo foram mantidos. Novas capturas reais dos menus e a homologação visual continuam pendentes por falha do navegador de testes.

## Telas com acesso direto

Estas telas não têm um caminho completo rastreado desde uma entrada do menu atual. O guia informa o acesso direto e coloca o botão no início, sem inventar uma opção lateral.

- Lançamento de notas: `/admin/notas`
- Integrações de Ponto: `/admin/rh/ponto/integracoes`
- Reputação: `/admin/integracoes/reputacao`
- Disciplinas: `/professor/disciplinas`
- Nova disciplina: `/professor/disciplinas/nova`
- Entregas dos alunos: `/professor/entregas`
- Central de notas: `/professor/notas`
- Progresso dos alunos: `/professor/progresso`
- Provas: `/professor/avaliacoes`
- Atividades do aluno: `/aluno/atividades`
- Minhas notas: `/aluno/notas`
